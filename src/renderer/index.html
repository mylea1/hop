HELLO, NEIGHBOR

Better together.

Open Hop on both computers, connect to the same Wi-Fi or LAN, and you’re a hop away.

On your Mac

Allow Local Network access when asked. You can change this in System Settings → Privacy & Security → Local Network. Allow incoming connections if macOS Firewall asks.

On your Windows PC

Allow Hop through Windows Firewall on your private network. If you trust your downloaded build, SmartScreen’s More info → Run anyway opens an unsigned app.

Can’t see each other?

A guest network, VPN, or router’s client isolation may block local discovery. Hop needs UDP 47800 and its local TCP port allowed.
